# Bloopville Website

A character/IP merchandise website inspired by the layout style of modern brand sites.

## Project Structure
- `index.html` - Homepage
- `assets/css/style.css` - Main stylesheet
- `assets/js/main.js` - Main JavaScript
- `assets/images/` - Place your images here
- `pages/` - Subpages (characters, products, about, contact)

## How to Run
1. Open `index.html` in any web browser.
2. For development, use Live Server in VS Code.

## Features
- Responsive design
- Character showcase
- Product grid
- Team section
- Contact CTA
